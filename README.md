# Android Intent Research

## How to Check the Structure of Android Parcel

### Step-by-Step Guide to Using 010 Editor

1. **Download and Install 010 Editor**
   - Visit the [010 Editor website](https://www.sweetscape.com/download/010editor/) and download the software.
   - Install the editor on your system. Note that it offers a free trial for 30 days.

2. **Prepare the Files**
   - Locate the `bad_parcel_payload.bin` file, which is generated by the adversary app. The payload is hidden in `item[3]`.
   - Locate the `bad_parcel_unparceled_twice.bin` file, which is the result of two rounds of serialization/deserialization and is fed into the victim app.

3. **Open the Files in 010 Editor**
   - Launch 010 Editor.
   - Open one of the `.bin` files (`bad_parcel_payload.bin` or `bad_parcel_unparceled_twice.bin`) using the editor.

4. **Load the AndroidBundle.bt Script**
   - Open the `AndroidBundle.bt` script in 010 Editor. This script is specifically designed to decode the Parcel binary structure.
   - Navigate to the `Template` menu and select `Open Template` to load the `AndroidBundle.bt` script.
   - Once loaded, go to the `Template` menu again and select `Run` to apply the script to the opened `.bin` file.

5. **Analyze the Parcel Structure**
   - Once the script is executed, the structure of the Parcel binary will be displayed.
   - Examine the decoded data to understand the layout and identify any hidden payloads or anomalies.

### Notes
- Ensure that the `AndroidBundle.bt` script is compatible with the version of 010 Editor you are using.
- If you encounter any issues during the process, refer to the documentation provided with 010 Editor or seek assistance from the project maintainers.
